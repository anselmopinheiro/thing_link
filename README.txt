Como usar (GitHub Pages)

1. Criar um repositório no GitHub (ex.: google-sites-hotspots)
2. Enviar estes ficheiros para a raiz do repositório:
   - index.html
   - style.css
   - app.js
   - data.json
   - pasta img/ (com google-sites-editor.png)
3. Ativar GitHub Pages:
   - Settings -> Pages
   - Source: Deploy from a branch
   - Branch: main / (root)
4. Abrir o URL do Pages.

Editar conteúdos
- Abrir data.json
- Para cada ponto (1 a 12), editar title e text.
- Se quiser link: preencher linkUrl e (opcional) linkText.
- Se quiser vídeo incorporado (YouTube): preencher videoEmbed com https://www.youtube.com/embed/ID

Incorporar no Google Sites
- Inserir -> Incorporar -> URL
- Colar o URL do GitHub Pages

Nota
- As posições dos pontos (pos.left, pos.top) foram calculadas a partir da imagem fornecida.
